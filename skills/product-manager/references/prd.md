# PRD

One page unless the owner asks for more.

## Shape
- Problem: who, what they are trying to do, what stops them, with the evidence (a quote, a number, a competitor example, with a source).
- Goal and success metrics: one goal, the metric, today's number if known, the target, how it is measured.
- Users and use cases: the main user and the top 2 scenarios.
- Requirements: must have, nice to have, out of scope. Write each as "The user can ...", so it can be tested.
- Design and build notes: open design questions, data or auth implications, numbers still needed.
- States and edge cases: empty, loading, error, and the odd case.
- Risks and open questions: each with an owner.
- Rollout and learning: how it ships, what to check after, and when to keep, change, or kill it.
