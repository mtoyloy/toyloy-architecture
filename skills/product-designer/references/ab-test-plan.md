# A/B test plan

## Steps
1. The question: what behavior are we trying to change, and what is the one metric?
2. Hypothesis: "If we change X, then Y will improve, because Z."
3. Test one variable. Describe variant A (control) and B in plain words, with the exact copy or layout difference.
4. Name the primary metric, one guardrail metric, and what counts as a win.
5. Be honest about sample size. Aisle is early and traffic is small. If volume is too low for a real test, say so and suggest cheaper options: 5 user interviews, a fake-door or smoke test, a preference test between two mockups, or a before/after comparison.

## Output
- A short plan: hypothesis, variants, metric, guardrail, audience, duration, decision rule.
- Write the decision rule before the test starts, so the result cannot be argued afterward.

## Reading results
- Apply the decision rule from the plan. Report numbers with sample sizes.
- Never call a result significant without the numbers. Flag novelty effects, tiny samples, and peeking.
- Building the variants is outside this skill.
