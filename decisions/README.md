# Decisions

One file per decision, so nobody has to re-ask why.

- Name: `YYYY-MM-DD_short-slug.md`.
- Keep each file under 30 lines.
- A later decision that replaces an earlier one gets a new file and links the old one under "Replaces".

Template:

```
# <Decision, one sentence>

- Date:
- Decided by:
- Why:
- Replaces:
```
